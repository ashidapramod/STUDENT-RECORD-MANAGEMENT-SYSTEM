 # Student Record Management System

A simple **C-based project** to manage student records using a menu-driven interface.

## Features

- Add new student records
- Delete student records
- View all student records
- Modify student details
- Sort and reverse records
- Save and load records using file handling

## Built With

- C Programming
- Singly Linked List
- Structures and Pointers
- File Handling

## How to Run

Compile:

```bash
make
```

Run:

```bash
./student
```

## About

This project was developed to practise C programming concepts, including linked lists, pointers, dynamic memory allocation, and file handling.
